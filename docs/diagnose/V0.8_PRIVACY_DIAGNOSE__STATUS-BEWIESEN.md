# Diagnose-Privacy V0.8

Vor Erzeugung wird eine Vorschau angezeigt.

Standardmäßig ausgeschlossen:
- Memo-Text
- PIN
- Tokens/Secrets
- vollständiger Home-Pfad

Enthalten:
- Tool-/Build-Version
- Plattform und Python-Version
- verkürzte Projekt-/DB-Bezeichnung
- Integritätsstatus
- Inhaltszähler
- Lösungshinweise

Kein Versand erfolgt automatisch.
