# Sprachaufnahme V0.11

## Linux
`FFmpeg → WAV-Staging → Stop → Dateigröße/Exit prüfen → AssetManager → SHA-256 → Commit → Manifest`.

Ein synthetisches FFmpeg-Signal beweist die Aufnahme-/Commit-Pipeline. Es beweist **nicht**, dass in der Build-Umgebung ein physisches Mikrofon vorhanden oder freigegeben ist. Reale Mikrofon-Evidence bleibt ein Zielsystem-Gate.
