# 🔥 V0.12 Failure-Matrix – BEWIESEN

| Fall | Ergebnis |
|---|---|
| Kill nach Asset-Journal | 🟢 Rollback |
| Kill nach Staging | 🟢 Rollback |
| Kill nach Datei-Commit | 🟢 Manifest wird rekonstruiert |
| Kill nach Manifest-Commit | 🟢 Transaktion wird finalisiert |
| ENOSPC / Disk-full Injection | 🟢 kein Final-Asset ohne Recovery |
| Permission denied Injection | 🟢 kein Final-Asset |
| Read-only Preflight | 🟢 vorhanden |
| beschädigtes DB-Backup | 🟢 Restore verweigert |
| beschädigtes Asset | 🟢 Quarantäne |
| DB + Asset Full Restore | 🟢 frischer Projektordner verifiziert |

**Offen:** echte Disk-full-/Read-only-Injektion auf den Zielgeräten. Deterministische Failure-Injection ist kein Ersatz für physische Zielsystem-Evidence.
