# Dokumente / PDF V0.11

- PDF: interner read-only Viewer über validierten lokalen Asset-Endpunkt.
- TXT/MD: kontrollierter Editor mit `expected_revision`, Temp-write, SHA-256 und Revisionssnapshot.
- DOCX/RTF: read-only/extern öffnen bis ein formatbewusster Editor vorhanden ist.
- Jede Textänderung behält bis zu 50 Revisionsmetadaten und eine Snapshot-Datei.
- Manipulierte Dateien werden vor Bearbeitung abgelehnt.
