# V0.8 Responsive Layout Gate

Verbindliche Viewports:
- 390 × 844
- 768 × 900
- 1366 × 768
- 1920 × 1080

Akzeptanz:
- kein horizontaler Dokument-Overflow
- Kernnavigation erreichbar
- Schnellmemo erreichbar
- Arbeitsbereich erreichbar
- Monatskalender bedienbar
- Touch-/Focus-Ziele sichtbar
- lange Listen dürfen intern scrollen

Chromium wird automatisiert versucht. Firefox wird nur PASS, wenn eine echte lauffähige Firefox-Browserengine vorhanden ist; andernfalls BLOCKED.
