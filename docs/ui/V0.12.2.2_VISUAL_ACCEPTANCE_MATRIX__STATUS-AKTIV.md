# V0.12.2.2 – Visual Acceptance Matrix

## Ziel
Alle Ansichten müssen bei Schrift- und Arbeitsbereichsvergrößerung sichtbar bleiben, ohne andere Elemente zu überdecken oder über Container-/Fensterränder zu laufen.

| Viewport | Schrift | Bereich | Erwartung |
|---|---:|---:|---|
| 1366×768 | 100 % | 100 % | Desktop kompakt, keine horizontale Seitenüberläufe |
| 1600×900 | 100 % | 100 % | volle rechte Tool-Info und Darstellungskarte |
| 1600×900 | 150 % | 150 % | Module ordnen sich neu, kein Clipping |
| 1600×900 | 200 % | 200 % | einspaltige Modulformulare, Navigation weiter erreichbar |
| 1920×1080 | 200 % | 100 % | große Schrift ohne Überdeckung |
| 390×844 | 100 % | 100 % | Mobile Drawer, Darstellung zweizeilig/einspaltig |

## Muss-Kriterien
- kein Button oder Eingabefeld liegt über einem anderen Element
- keine sichtbare UI läuft über Karten-/Arbeitsbereichsränder
- Eingabefelder haben klaren warmen Kontrast und sichtbaren Fokus
- linke Navigation bleibt lesbar und bedienbar
- Darstellungseinstellungen bleiben oben erreichbar
- Desktop-Dateiauswahl ist primärer Importweg
- technische Rohdaten sind standardmäßig eingeklappt
