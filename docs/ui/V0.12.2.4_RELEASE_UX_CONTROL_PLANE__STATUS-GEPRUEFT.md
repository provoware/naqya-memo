# V0.12.2.4 – Release UX + GitHub Control Plane

## UX
- Navigation trennt Symbol und Beschriftung.
- Arbeitsbereich zeigt pro Modul einen konkreten Orientierungssatz.
- Feldhilfen richten sich nach Hilfemodus und reduzieren dadurch Dauerrauschen.
- Footer zeigt im Normalbetrieb nur System/A11Y; Diagnosewerte bleiben aufklappbar.
- Buttons besitzen klarere Primär-/Sekundär-/Gefahr-Hierarchie.
- 44px Zielgröße, sichtbarer Tastaturfokus und Reduced-Motion-Unterstützung.

## Repository
- neue `.gitignore`, `.gitattributes`, `.editorconfig`
- Source-Contract-Workflow für Python/Node/UI/Mobile
- CONTRIBUTING und einfache Startanleitung
- historische GitHub-Architektur bleibt über Backupbranches referenzierbar

## Sicherheitsgrenze
Diese Iteration erhöht keinen realen Release-Gate-Zähler.
Browser-, Mikrofon-, Android- und iOS-Gates benötigen weiterhin reale Zielsysteme.
