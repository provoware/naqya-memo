# V0.12.2.2 Release UI Consistency

## Auslöser
Reale Linux-Screenshots zeigten Versionsdrift, abgeschnittene Statuswerte, technische Rohdaten im Laienbereich, primären Dateipfad-Import und unnötige Scrollzonen.

## Vertrag
1. Version ist Single Source of Truth.
2. Statusanzeigen dürfen nichts behaupten, was nicht gemessen wurde.
3. Technische Rohdaten sind standardmäßig eingeklappt.
4. Dateiauswahl ist Primärworkflow; Pfad ist Profi-Fallback.
5. Bereichszoom darf horizontale Bedienbarkeit nicht erzwingen.
6. Keine Änderung erhöht den Release-Gate-Zähler.
