# Plattform-Evidence V0.10

## Linux
Native Runtime Probe:
- xdg-open
- xdg-email
- notify-send
- ffmpeg
- ffprobe
- Projektordner-Schreibprobe

## Android
`CONTRACT_ONLY`, kein echtes Gerät in dieser Build-Umgebung.
Benötigt später: Notification Permission, Scoped Storage, Microphone Permission, Background Restrictions.

## iOS
`CONTRACT_ONLY`, kein echtes Gerät in dieser Build-Umgebung.
Benötigt später: Notification Authorization, App Sandbox/Document Picker, Microphone Authorization, Background Limits.

**Regel:** fehlende native Geräte-Evidence wird niemals als PASS ausgegeben.
