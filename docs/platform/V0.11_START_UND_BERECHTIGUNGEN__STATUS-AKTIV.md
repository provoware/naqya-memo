# Start- und Berechtigungspfade V0.11

## Linux
Launcher → Python-Preflight → Projektordner → Service → Browser. Mikrofon nur beim Start einer Aufnahme.

## Android
App-Start ohne pauschale Mikrofonfreigabe. `RECORD_AUDIO` erst bei Aufnahme; `POST_NOTIFICATIONS` erst für Reminder. Scoped Storage statt freiem Dateisystem.

## iOS
App-Sandbox; Mikrofon-/Notification-Autorisierung erst bei Nutzung; Dateien über Document Picker/Share Sheet. Kein autonomes Installieren von Systemabhängigkeiten.
