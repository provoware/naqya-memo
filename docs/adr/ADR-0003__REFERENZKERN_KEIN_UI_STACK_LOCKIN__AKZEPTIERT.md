# ADR-0003 — Technologiegrenze V0.2
**Status:** AKZEPTIERT

V0.2 implementiert **keine finale UI-Technologieentscheidung**. Der ausführbare Python-Kern in `core/reference_python/` ist eine Referenz- und Acceptance-Implementierung der Datenverträge, nicht automatisch der spätere Produkt-Runtime-Stack.

Damit bleibt die Wahl zwischen Flutter/Dart oder einer anderen geeigneten plattformübergreifenden UI/runtime offen, ohne die Datenverträge erneut zu erfinden.
