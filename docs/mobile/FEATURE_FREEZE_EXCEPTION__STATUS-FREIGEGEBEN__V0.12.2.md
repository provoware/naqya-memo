# Feature-Freeze Exception V0.12.2

Die gewählte Release-Strategie ist **Multi-Platform V1.0**. Deshalb darf der Feature-Freeze ausschließlich für die bereits versprochene Plattform-Parität geöffnet werden.

## Erlaubt
- Android/iOS Runtime-Portierung bestehender Funktionen,
- Native Permission-/Audio-/Reminder-/Share-Adapter,
- Build-/Signing-Struktur,
- Contract-Parity-Tests,
- Device-Acceptance-Harness.

## Verboten
- neue Fachmodule,
- neue Produktideen,
- zusätzliche Gameplay-/Workflow-Funktionen,
- UI-Re-Design ohne Release-Notwendigkeit.

Nach Schließen der Plattformlücke gilt wieder vollständiger Freeze bis V1.0 RC.
