Pipeline:
`Systemscan → Capability Scan → Berechtigungsstatus → Projektordner-Preflight → Profil/Settings → Checkpoint → READY`

## Sicherheitsgrenze
Automatisch repariert werden nur sichere lokale Strukturen wie fehlende Projekt-Unterordner. Rechte, externe Pfade oder Plattformrestriktionen werden niemals umgangen.

## Ampel
- GREEN: fachlich bereit
- YELLOW: Nutzeraktion erforderlich, kein Datenfehler
- RED: sicherer Start blockiert
