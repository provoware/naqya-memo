# V0.9 Asset Contract

## Pipeline
PRE → Extension/Kind/Quota → Temp Copy → flush/fsync → SHA-256 → atomic Commit → Manifest → Post-Validation

## Regeln
- Audio und Dokumente werden nie direkt in den finalen Ordner geschrieben.
- Assets besitzen stabile UUID und SHA-256.
- Manipulierte Assets werden erkannt und in Quarantäne verschoben.
- Quarantäne ist kein Löschen.
- Asset-Backup prüft die Kopie erneut per Hash.
- Quota schützt Projekt und Backups vor unkontrolliertem Wachstum.
- UI besitzt keinen direkten Dateischreibpfad.
