# V0.8 Interaction & Recovery Contract

- Bearbeiten benötigt aktuelle Revision.
- Kein stilles Überschreiben.
- Memo, Todo und Termin können kontrolliert in den Papierkorb.
- Wiederherstellen ist eine Mutation mit Revisionsprüfung.
- Undo/Redo bleibt persistent und läuft über die Mutation Queue.
- Kalender-Tagesfarbe ist persistente Domain-Entity.
- Fünf Kalenderfarben bleiben eine feste, editierbare Legende.
- Diagnosebericht wird erst nach Privacy-Vorschau und ausdrücklicher Bestätigung erzeugt.
- UI greift niemals direkt auf SQLite zu.
