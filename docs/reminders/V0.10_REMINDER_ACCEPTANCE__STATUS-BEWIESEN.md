# Reminder Acceptance V0.10

## Bewiesen
- fällige Reminder werden deterministisch erkannt
- zukünftige Reminder werden nicht zu früh ausgeliefert
- Zustellung wird pro Plattform/Entity/Reminderzeit dedupliziert

## Nicht behauptet
Der neutrale ReminderEngine-Nachweis beweist keine native OS-Zustellung.
Linux kann lokal separat geprüft werden.
Android und iOS bleiben bis zu realen Device-/Runner-Tests `CONTRACT_ONLY`.
