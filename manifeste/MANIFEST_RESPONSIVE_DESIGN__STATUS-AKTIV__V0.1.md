# 📐 MANIFEST_RESPONSIVE_DESIGN — V0.1
- Mobile-first Layoutregeln, aber Desktop-Dashboard voll ausnutzen.
- Breakpoints werden aus Inhalt und Mindestbedienflächen abgeleitet.
- Mindest-Touchziel 44 CSS px bzw. plattformäquivalent.
- 200-%-Zoom ohne Funktionsverlust.
- Header priorisiert: Identität → nächste 10 Aufgaben → Status → Schnellaktion.
- Sidebars werden auf kleinen Displays zu Drawer/Sheets.
- Lange Listen dürfen scrollen; Kernaktionen bleiben sichtbar/sticky.
- Einzelbereiche dürfen separat zoomen, sofern Fokus/Lesefluss erhalten bleibt.
